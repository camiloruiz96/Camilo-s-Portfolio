Camilo Ruiz Portfolio v3
=========================

Open index.html in a browser or deploy this folder to GitHub Pages.

Included assets:
- game-studio.webp: optimized portfolio artwork screenshot
- backoffice-sanitized.webp: cropped and anonymized back-office screenshot
- backoffice-detail.webp: detail crop used in the layered SaaS case-study presentation
- boom-chat.webp: cropped BoomStudies/CX chatbot screenshot

The original uploaded PNGs are retained in assets/ as *-source.png for reference.

Content is intentionally product-led rather than CV-led. The strongest measurable stories are the Game Studio (+60% player sessions), B2B Back Office (~20% processing-time reduction) and BoomStudies chatbot automation (20% CX workload reduction).
